Google Sheet sync
Google Sheet setup (one time)
1. Create a Google Sheet with headers:
Name | Phone | Products | Channel | Status | Date | Notes

2. Open Extensions → Apps Script
3. Paste this code and deploy as Web App:
function doPost(e) { var s = SpreadsheetApp .getActiveSpreadsheet() .getActiveSheet(); var d = JSON.parse(e.postData.contents); s.appendRow([d.name,d.phone, d.product,d.channel, d.status,d.date,d.notes]); return ContentService .createTextOutput('{"ok":true}') .setMimeType( ContentService.MimeType.JSON); }
4. Set access to Anyone, copy the URL above.
